AI 记 (AiJi) 隐私政策

最后更新：2026-08-24 · 适用于 Android 应用 v2.5.x

1. 我们是谁 / Who We Are

「AI 记」（AiJi）是由 董成麒（Chengqi Dong）独立开发的通用记录工具，面向个人用户提供本地优先的笔记、语音、照片与 AI 辅助整理服务。

AiJi is a personal note-taking app developed by Chengqi Dong. It offers a local-first experience for capturing text, voice, photos, and AI-assisted organization.

2. 数据收集原则 / Data Collection Principles

本地优先，服务端不持久存储内容。

  • 你的所有记录条目（文字、照片、音频、视频）均存储在设备本地 IndexedDB 中。
  • 应用采用 BYOK（Bring Your Own Key）模式：LLM / STT 的 API Key 由你自行配置并仅保存在本地，我们不会读取或上传你的 Key。
  • 若你使用云端账号（network 账号），服务端仅代理鉴权、套餐与配额查询，不保留你的笔记内容。

All entries are stored locally in IndexedDB. API keys for LLM/STT are configured by you and kept only on the device. The backend acts solely as an auth/plan/quota proxy and does not persist your notes.

3. 后端代理说明 / Backend Proxy

为降低使用门槛，应用提供可选的后端代理服务：

  • 语音转写 音频片段上传至后端进行 STT（语音识别），识别完成后音频数据不保留。
  • AI 分析 若你未配置自有 Key，可选择由后端代理转发至大语言模型；转发内容即当前条目标题与正文，处理完成后不保留。
  • 地理编码 地理位置信息通过后端代理查询高德地图服务，用于展示地点名称。

Optional backend proxies: STT (audio transcribed and not retained), LLM analysis (content forwarded and not retained), and geocoding (location queried via Amap).

4. 权限用途 / Permissions

  • 相机 / Camera：用于拍摄照片或视频并添加到记录中。
  • 麦克风 / Microphone：用于语音输入与语音转文字。
  • 位置 / Location：用于为记录附加地理位置信息（可选，默认关闭）。
  • 通知 / Notifications：用于在设定时间发送提醒。
  • 精确闹钟 / Exact Alarm：确保提醒在指定时间准时触发（Android 12+）。
  • 安装包 / Install Packages：用于应用内检测新版本并引导系统更新（仅在你主动确认时触发）。

Camera and microphone are for media capture. Location is optional for geo-tagging. Notifications and exact alarms are for reminders. Install packages is for in-app update prompts.

5. 数据安全 / Data Security

  • 本地数据使用浏览器标准 IndexedDB 存储，受设备操作系统沙箱保护。
  • 网络传输使用 HTTPS（后端已启用 TLS）。
  • 账号密码经 bcrypt 哈希后存储，服务端不保存明文密码。
  • JWT 令牌用于身份校验，支持登出与刷新。

Local data is protected by OS sandboxing. Network traffic uses HTTPS. Passwords are hashed with bcrypt. JWT tokens are used for authentication.

6. 你的权利 / Your Rights

  • 导出：可在设置中导出全部数据为 JSON。
  • 删除：可在设置中「清除本地数据」或「注销云端账号」；注销后服务端关联信息将被删除。
  • 撤回授权：可在系统设置中随时关闭相机、麦克风、位置等权限。

You can export all data as JSON, clear local data, or delete your cloud account at any time. System permissions can be revoked in device settings.
