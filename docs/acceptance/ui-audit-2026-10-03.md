## MAJOR

### M1. categories「心情」tab 违反产品身份铁律 §1（情绪不是轴）

- 现象：类别屏维度切换为 类别/时间/**心情**/项目/人物/地点 —— 情绪成了独立导航轴。
- 铁律原文（CLAUDE.md §1）：「情绪不是轴。情绪只是众多可被 LLM 检测的可选侧面之一，
  不当独立导航轴、不当强制采集字段。」Figma 原型搜索页的「情绪」chip 是铁律前的
  旧设计，app 搜索已正确地没有它，但 categories 把旧概念做成了 tab。
- 代码坐实：
  - `src/ui/screens/categories/helpers.ts:7` — `LensKind` 含 `'mood'`
  - `src/ui/screens/categories/ViewSwitcher.tsx:12` — tab 渲染
  - `src/ui/screens/categories/FacetLens.tsx:9,23` — mood 维度取数
  - `src/ui/screens/categories/index.tsx:129` — view 分支
- 边界（勿误伤）：情绪作为 **facet**（LLM 可选侧面）合法——detail 屏「情绪·兴奋」chip、
  EntryAi.facets.mood 均保留不动；只摘除**导航轴**。
- 修法：ViewSwitcher 去 mood 项 → LensKind 去 'mood' → index.tsx 分支清理 →
  i18n `categories.lens.mood` key 删除（zh+en）→ FacetLens mood 分支成死代码一并清
  （facet 数据本身仍在 detail 使用，FacetLens 仅服务于该 tab）。

## MINOR

### m1. summary 旧周卡日期区间重复
周/月卡标题已是「9/14–9/20」，卡片右侧又重复同样区间文本。去右侧重复（或右側改显示
条目数等增量信息）。落点：`src/ui/screens/summary/`。

### m2. onboarding 标语断行寡字
首屏「生活片段 / 跳脱想法 / 项目进展——随手记，AI 帮你理」换行后「理」字独占一行
（390px 视口）。加 nowrap 或改文案断点。落点：`src/ui/screens/onboarding/`。

### m3. settings 行尾内容被采集 FAB 遮挡
设置是主 tab 路由（有 FAB），「语言」行右侧当前值在特定滚动位置被 FAB 盖住。可滚动
避开，但首屏正好遮住。给列表底部加 FAB 高的 padding 或行尾留右安全距。
落点：`src/ui/screens/settings/`（或 AppShell 主路由内容容器统一加 padding-bottom）。

## 观察项（非缺陷，不本轮修）

- **O1. detail 无波形播放器**：Figma 有紫色波形 + 时长；app 为单行音频行（样例数据无
  blob 时降级「音频不可用（样例）」）。真实录音条目有 HTML5 audio。属有意简化。
- **O2. detail 无「LLM 检测到·待办」行动卡**：Figma v2 设计了待办检测卡（创建待办/
  提醒我/忽略）；现产品走 chat 意图路径（ActionConfirmBubble）。是 feature 路线差异，
  不是 UI 漂移；若要补属新 feature（可与 P-D 主动触达合并考虑）。
